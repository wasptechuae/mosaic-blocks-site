# Mosaic Blocks site

Static landing, privacy policy and support pages for the Mosaic Blocks game, served by GitHub Pages (Jekyll) from `main` / root. Holds no game code and no secrets. The contact address lives only in `_config.yml` as `contact_email`. Fonts are self-hosted (SIL OFL 1.1, licences in `assets/fonts/`). The policy text mirrors `docs/store/privacy-policy.md` in wasptechuae/mosaic-blocks.
